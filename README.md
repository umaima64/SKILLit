# SKILLit

SKILLit is a frontend-only hackathon MVP for a skill-sharing and collaboration marketplace. It demonstrates three core models in one app:

- Skill exchange between people with complementary capabilities
- Paid service marketplace for mini-service transactions
- Project and collaboration flow for team-based work

## Features

- Landing page and app shell
- Demo authentication with LocalStorage persistence
- User discovery and matching logic
- Request workflow and notifications
- Project and collaboration views
- Service marketplace and demo checkout
- Reviews and feedback flow
- Responsive layout for desktop and mobile screens

## Tech stack

- React 19
- Vite
- Bootstrap 5
- React Router DOM
- LocalStorage for demo data persistence

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## GitHub Pages note

The Vite config is set to use a relative base path so the app works cleanly when built for GitHub Pages hosting.
